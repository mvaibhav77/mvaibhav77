### Featured Projects

#### [async-merge](https://github.com/mvaibhav77/async-merge)
*A Go-based Git merge driver combining AST-aware conflict analysis with LLMs.*

- Resolves three-way (`diff3`) merge conflicts using structural code analysis and LLM-assisted merging.
- Uses Tree-sitter to identify enclosing functions and validate merged syntax, failing safely when parsing fails.
- Supports automatic failover between cloud models via Groq and local models via Ollama.
- Includes unit, integration, and end-to-end tests in CI.

**Stack:** Go · Tree-sitter · Git Internals · LLMs

#### [Multi Antivirus Utility Tool](https://github.com/samrakshaaa/MAUT)
**Winner — Smart India Hackathon 2024**

- Developed a multi-engine antivirus scanning tool that runs four antivirus engines concurrently in isolated virtual environments.
- Engineered a Rust backend to coordinate scans and manage file access across virtual machines.
- Optimized file access using symbolic links to avoid duplicating file contents.

**Stack:** Rust · Tauri · React · QEMU · Virtual Machines
